# 有理猫 YOULI CAT — 个人 IP 品牌手册

一只穿紫金祥云袍、持「有理槌」的黑猫，口号「有理，不慌。」

本仓库为个人 IP 品牌手册网页版（cat-zine 风格），由 index.html + assets/ 构成，纯静态，可直接部署 GitHub Pages。

## 在线浏览

开启 GitHub Pages 后访问：`https://<你的用户名>.github.io/<仓库名>/`

## 内容板块

创意概述 · 命名与口号 · 角色设定 · 标志系统 · 色彩 · 字体 · 表情系统 · 动作姿态 · 应用规范 · 品牌口吻

## 文件说明

- `index.html` — 手册主页面
- `assets/` — 图片素材（主视觉、印章、表情、动作、周边样机等）
- `有理猫IP品牌手册.pdf` — PDF 版（30 页）

本形象为个人原创 IP，转载请注明出处。
